# Bienvenido a mi blog 🚀

Este proyecto corresponde a mi **sitio web personal**, desarrollado con **Next.js 14 (App Router)**, **React** y **Sass** como preprocesador de estilos.  
El objetivo principal es tener un espacio donde compartir mis **proyectos de software, artículos técnicos y reflexiones**.

---

## 🚀 Características principales

- **Next.js (App Router)**: Arquitectura moderna con soporte para rutas dinámicas y segmentación de layouts.  
- **Sass (SCSS)**: Estilos organizados y modulares sin depender de frameworks externos.  
- **MDX para contenido**: Cada proyecto y artículo está escrito en MDX, lo que permite mezclar texto y componentes de React.  
- **Diseño adaptable (Responsive)**: Optimizado para móviles, tablets y pantallas grandes.  
- **Optimización SEO**: Metadatos, títulos y slugs personalizados para cada página.
